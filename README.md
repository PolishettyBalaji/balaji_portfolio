# Balaji Space Portfolio

A responsive, space-inspired portfolio for Polishetty Balaji, built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract this folder.
2. Open `index.html` in a browser. For the best local development experience, use VS Code with the Live Server extension.

## Resume
The website expects your resume at `assets/sasken.pdf`. Replace this file with your latest approved resume PDF if you update it.

## Personalize before publishing
- Check your name, location, email, LinkedIn, and GitHub links in `index.html`.
- Update project descriptions and add GitHub repository links when you are ready.
- Do not publish private or sensitive information.

## Publish with GitHub Pages
1. Create a new public GitHub repository named `balaji-portfolio` (or another name you prefer).
2. Upload all files and folders in this project, keeping `index.html` at the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for the deployment to finish. GitHub will show the published website URL in the Pages section.

GitHub Pages serves static files. This project does not require a Java backend. Java is showcased as a technical skill; a Spring Boot backend can be added separately if needed.
